# OpenCirkle v23 — Navigation & Mobile UX Upgrade

- Polished the existing mobile bottom navigation without changing its route behavior.
- Added visible Explore, Crypt, and Profile labels so every primary destination is clear at a glance.
- Added active-page semantics and helpful accessible labels/titles for navigation buttons.
- Improved minimum touch target sizing and adjusted the dock spacing for narrow screens.
- Positioned the floating navigation using the device safe-area inset to reduce overlap with Android/iOS gesture areas.
- Preserved the Home tab, post composer, link-preview changes, Firebase integration, and existing app features.
